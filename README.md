# nosurzhik-site

Static marketing + legal site for the **No Surzhik** iOS app. Plain HTML/CSS,
no build step. Deployed on Vercel.

| Path | Purpose |
|---|---|
| `/` | Landing page |
| `/privacy` | Privacy policy (uk + en) — App Store Connect "Privacy Policy URL" |
| `/terms` | Community rules + EULA (App Store guideline 1.2) |
| `/support` | Support / contact — App Store Connect "Support URL" |
